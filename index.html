This strip 0 of 5 scans

Place one pad in front of the sensor and press Scan. The app reads it 5 times over 5 seconds, averages the readings, and works out which parameter it is by itself.

    Which parameters should the app look for?

    Five is a good number. Pick pads whose colours don't look alike, and check the look-alike list below.

    Look-alike check

    Pairs of reference colours from different parameters that are close enough to be mixed up. A "difference" under 12 is a risk. If a pair shows up here, the app will ask you to choose when it sees that colour.

      Reference colours

      "Placeholder" colours are rough copies of a typical strip chart, so you can try the app straight away. For real use, dip a strip in a sample whose level you know, wait the reading time printed on the bottle, put that pad in front of the sensor and click Record on the matching row. Needs a connected, calibrated Arduino.

      1. Wire the sensor

      Waveshare TCS34725 colour sensor to an Arduino Uno, five wires:

      Sensor pinVCCGNDSDASCLLED
      Arduino pin5VGNDA4A5D6

      2. Install the firmware

      "Firmware" is the small program that runs on the Arduino and reads the sensor. You only need to do this once per board. Plug the Arduino in with its USB cable, close Arduino IDE if it's open, then click the button and pick your board from the list.

      Go back to the Scan tab, calibrate with the white card, and start scanning.
